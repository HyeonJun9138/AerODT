# 승객 초안용 사람 11종

Kenney Blocky Characters 2.0 (CC0). a,b,c,e,f,i,j,k,m,p,q.

일상복, 정장, 제복, 안경과 수염 등 외형 변형을 포함한다. 로봇/괴물/닌자는 제외했다. 같은 블록형 몸체의 텍스처 변형이며 서로 다른 인체 체형 모델은 아니다.

각 모델은 대기/걷기/앉기 등 27개 부품별 애니메이션, 약 124~131 KiB, 72 삼각형이다. 원본 키 2.7 좌표 단위는 실측 인체 키가 아니므로 배치 시 보정해야 한다.

GLB 정적 검증과 기본 WebGL 렌더 검증 완료. 애니메이션 재생 및 탑승 연동은 미검증.
