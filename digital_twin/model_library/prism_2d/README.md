# PRISM 2D 관측 기반 예측 패키지

`prism_2d_v1`은 PRISM의 `20260815_010810_full5x_s6` 학습 실행을 가져온 패키지다. 완료된 full5x 실행 가운데 가장 최근의 26 epoch 실행이며, 3개 궤적 모드, 10개 객체 슬롯, 객체 간 상호작용과 종류 출력이 모두 있는 모델을 선택했다. demo, 중단된 실행, ablation과 평가 전용 실행은 선택하지 않았다. seed 6의 성능이 다른 seed보다 낫다는 의미는 아니다.

`manifest.json`은 원본 상대 경로와 SHA-256, 선택 근거, 학습 구성을 보존한다. `model.pt`는 원본 `final/model_final.pt`와 바이트 단위로 같다. 실행은 `torch.load(..., weights_only=True)`와 엄격한 state dict 검사를 사용하며, 임의 pickle 실행이나 외부 프로젝트 import를 하지 않는다. 원본 PRISM은 읽기만 했다.

## 입력과 출력

- 입력은 0.5초 간격의 20개 슬롯이다. 첫 슬롯부터 마지막 슬롯까지는 9.5초이며, 누락 위치를 보간하지 않는다.
- 각 슬롯은 첫 관측과 최신 관측 두 개까지만 보존한다. 요청 시각보다 뒤의 관측은 사용하지 않는다. 활성 선택 기체와 우선순위가 높은 주변 16개는 15초 동안 이력 제거에서 보호하며, 보호 대상은 전체 128개 및 이력 저장 상한을 넘지 않는다.
- 표적 위치의 마지막 관측을 원점으로 두고, 관측 변위로 추정한 이동 방향을 x축으로 쓴다. 종류의 정답, 실제 미래 궤적, 실제 heading은 특징에 들어가지 않는다.
- 13개 특징과 정규화, 객체 슬롯 선정, 신경망 연산은 원본과 같다. 특징 함수에서는 학습 정답과 GT 메타데이터 읽기만 제거했다.
- 모델은 3개 가우시안 궤적을 0.5초 간격으로 15초까지 출력한다. Runner가 평균과 공분산을 선택 기체의 현재 위치를 원점으로 하는 ENU 좌표로 변환한다. 종류 출력은 정답이 아니라 모델의 분포다.
- 모델 라이브러리는 정의와 가중치를 소유한다. 과거는 `data/simulation/risk_history.py`, 추론과 미래는 `ai_pnp/risk_prediction.py`가 담당한다. 웹 환경에 torch가 없으면 응용프로그램이 별도 Python 실행 어댑터를 주입할 수 있다.

## 공개해야 하는 제한

관측이 없는 시뮬레이션 상태는 `experimental_simulation_state`로 표시한다. 실제 센서 관측이라고 부르지 않는다. 항법 posterior가 있는 경우 그 관측 시점의 위치를 사용하고, 수신이 갱신되지 않았으면 새 감지로 복제하지 않는다. 원본 관측 공분산이 없으면 10 m 등방 표준편차를 가정한다. posterior의 수평 표준편차가 있으면 등방 근사로 사용한다. ownship 슬롯의 0.5 m 표준편차 가정은 원본과 같다. 이러한 차이와 출처는 응답 provenance에 담긴다.

이 모델은 합성 2D 관측에서 학습했다. 현재 AeroDT 입력으로 옮기는 것은 실험적 적용이며, 3D 충돌확률, 공인 분리 기준, 회피 권고 또는 실제 교통에서 보정된 불확실성으로 해석하지 않는다. 고도는 현재 상대 고도만 표시하며 예측하지 않는다.

## 검증

`project_support/tests/web_live/test_prism_risk.py`는 감지 누락과 시계 재설정, 메모리 제한, batch 16개 제한, 표적 좌표 회전과 공분산 변환, 잘못된 출력의 원자적 거부를 검사한다. PRISM 원본이 로컬에 있으면 특징과 신경망 출력의 직접 비교도 실행한다.

2026-09-13 검증에서 원본 특징의 x/mask/frame과 원본 신경망의 5개 raw 출력이 실제 가중치를 사용해 완전히 일치했다. 수치 이식 검증이지 실제 항공 교통 예측 성능 검증은 아니다. 세부 실행 근거는 `project_support/prism_radar_work/model_verification.json`에 있다.
