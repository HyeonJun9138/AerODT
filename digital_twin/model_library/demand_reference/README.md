# 받은 수요 비율 원본

`departure_ratios.csv`, `arrival_ratios.csv` — 2026-09-10에 외부에서 받은 서울시 통행
수요의 출발·도착 비율. 행 하나가 한 지역이고, 값은 **서울 전체 통행 대비 비율**이다.

- 17개 행의 합은 1이 아니라 **0.803**이다(출발·도착 모두). 나머지 0.197은 우리가 버티포트를
  놓지 않은 지역의 몫이다. 그래서 이 값을 확률로 그대로 쓰지 않고 **가중치**로 쓰고, 실제
  비율은 그때 선택된 버티포트들 사이에서 다시 정규화한다.
- 지명은 이 파일이 쓰는 행정 구역 이름(`영등포·여의도`)이고, 우리 버티포트는 그 안에 놓인
  장소 이름(`여의도`)을 쓴다. 둘의 대응은 `demand_ratios.py`의 `PLACE_NAMES`에 있다.
- 인천에는 대응하는 행이 없다. 자료가 없다고 표시하고 평균(100%)에서 시작한다.

값 자체는 `demand_ratios.py`에 옮겨 적혀 있다. 이 폴더의 두 파일은 받은 그대로이며,
숫자가 어디에서 왔는지 확인할 때 본다.
