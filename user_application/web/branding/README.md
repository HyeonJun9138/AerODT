# AERODT 브랜드 로고

사용자가 제공한 PNG 원본을 변경 없이 보관한다. 로딩 중앙 제목과 푸터가 이 파일 하나를 공유하며 CSS로 표시 크기만 조절한다. 물리 자산/기체 3D 모델이 아니라 User/Application의 브랜드 자산이다.

- 원본: `aerodt.png` (2170 × 725, RGBA, 497,057 B) — 변경하지 않는다.
- SHA-256: `7ed1915d6c52635234158dd81d79363659ddb0c803d29f02a5b238650708ab10`
- 표시용: `aerodt-1520.webp` (1520 × 508, 186,604 B, 원본의 38%) — 원본을 Lanczos로 축소한 뒤 무손실 WebP로 인코딩했다. 보이는 모든 화소가 축소 결과와 동일함을 확인했고(투명한 화소 아래의 RGB만 다르다), 표시 최대 폭이 760 CSS px이므로 2배 밀도 화면까지 이 해상도로 충분하다.
- `index.html`은 `<picture>`로 WebP를 우선 사용하고 WebP를 지원하지 않는 환경에서는 원본 PNG를 사용한다. 두 위치(로딩 제목, 하단 출처 표시)가 같은 파일을 공유한다.
- 사용자 제공 자료이며 별도의 공개 이용 라이선스를 가정하지 않는다.
