# 다중 비행 수동 조종 · PSU 간단 사용법

**초반 출발을 원하면 계획 적용 후 재생 전에 수동 기체를 배정받으세요.** 초기 배정 시 도착 슬롯을 먼저 예약합니다. 해당 편의 계획 출발·준비 시각부터 시뮬레이션 시간 2분간 같은 출발지 자동편보다 출발 요청을 우선 받습니다. 재생 후 바로 `출발 준비 · 이동 요청`을 한 번 누르고, `지상 이동 허가`를 확인한 뒤 이동하세요. 2분 동안 요청하지 않으면 초기 우선권과 미사용 예약을 해제합니다. 이미 운항 중인 기체의 허가·점유는 유지됩니다.

**PSU 계기의 큰 행동 문구와 바로 아래 요청·보고 버튼을 따라갑니다.**
시각만 됐다고 자동으로 허가되지는 않습니다.

| 순서 | 조종사 행동 | PSU 응답 후 할 일 |
|---|---|---|
| 1 | 운항 시계(KST)·계획 GATE 출발 확인 | 정지 상태면 **상단 SIM 재생바** 또는 **조작 → 시뮬레이션 재생**을 누릅니다. PSU에는 재생 버튼이 없습니다. 다른 기체도 함께 운항합니다. |
| 2 | `출발 준비 · 이동 요청`을 한 번 누름 | `지상 이동 허가`를 받으면 표시된 출발 FATO로 이동합니다. **아직 이륙 허가는 아닙니다.** |
| 3 | FATO 중심에 정차 → `FATO 도착 · 이륙 요청` | `이륙 허가`를 확인하고 이륙합니다. 대기 응답이면 재확인합니다. |
| 4 | `이륙 완료 보고` | 접수 후 배정 항로를 따라 비행합니다. |
| 5 | `접근 순번 요청` | 기본 도착 예상 120초로 슬롯을 요청합니다. 예약된 착륙 시각과 FATO/GATE를 확인합니다. |
| 6 | 슬롯 시각 도달 → `최종 착륙 허가 요청` | `착륙 허가`를 확인한 뒤 최종 하강·착륙합니다. 예약 시각만으로 내려가면 안 됩니다. |
| 7 | 접지 → `착륙 완료 보고` | 배정 GATE로 지상 이동합니다. |
| 8 | GATE 중심 정차 → `GATE 도착 보고` | TURNAROUND에서 하차·충전을 요청합니다. |

- **출발 배정 대기**: 요청은 유지되고 PSU가 자동 재검토합니다. 반복 요청하지 않아도 됩니다. 선행 기체 이름과 대기 이유를 확인하고, `지상 이동 허가`가 표시될 때까지 GATE에서 기다립니다. `출발 요청 취소`를 누르면 접수를 취소합니다.
- **배정 검토 카운트다운**: 출발 허가나 확정 출발 시각이 아닙니다. 실제 점유가 계속되면 대기하며, 시각 도달만으로 움직이면 안 됩니다.
- **대기·거절·수신 지연**: 계기의 이유를 읽고 `지시 새로 확인` 또는 다음 요청 버튼으로 재확인합니다. 이륙/착륙 허가를 받기 전에는 해당 행동을 시작하지 않습니다.
- `이륙 슬롯`·`착륙 슬롯`은 자원 예약 시각입니다. `계획 GATE 출발`과 다릅니다. **미정은 허가가 아닙니다.**
- `대기 요청` 응답에 실제 대기 좌표가 없으면 지정 대기점이 발급된 것이 아닙니다.
- `조종 절차 · 최근 교신`을 열면 이 순서와 최근 요청/응답을 다시 볼 수 있습니다. 작은 글씨는 MFD `확대`를 사용합니다.
- 보고 버튼은 위치를 바꾸지 않습니다. 실제 이륙·접지·정차 관측과 맞지 않으면 이유와 함께 거절합니다.
- 자동 조종 입력을 생성하는 기능은 아닙니다. 허가 뒤 이동·이륙·비행·착륙은 조종사가 수행합니다.
