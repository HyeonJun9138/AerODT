# UAM 기종별 실내 및 조종석 시야 설계

상태: 대화에서 기능 범위 승인. 아래 상세 설계 검토 후 구현 단계로 진행한다.

## 승인된 목적

KP2의 반투명 창문을 기준으로 다섯 UAM 외형의 창문을 보완한다. 승객 정원만큼 좌석과 별도 조종사 1석을 만들고, 앞창을 통해 실제 3D 지도를 보면서 실시간 계기판을 확인하는 조종석 시야를 제공한다. 사용자 요청에 따라 실내 부품 크기와 위치는 각 외형에 맞춰 조정한다. 실제 기종의 인증된 설계나 공학적 인체공학 검증을 주장하지 않는다.

## 범위와 기존 상태

- 대상: `projectairsim_airtaxi`, `joby_s4`, `kp2a`, `amvlab_evtol`, `x_57`.
- 현재 다중 비행 정원은 Joby 2, AirTaxi 4, KP2 6, EVTOL 8석이다. 이는 AeroDT의 대표 외형 매핑이며 제조사 정원이 아니다. X57 기본은 단일 비행의 4석이다.
- 실제 선택 비행계획에 정원이 있으면 그 정원을 사용한다. 현재 탑승자 수에 따라 빈 좌석을 없애지는 않는다. 정원이 없는 화면에서는 위 기본값을 사용하며 승객 좌석과 조종사 좌석을 구분한다.
- 기존 KP2 유리는 `BLEND`, alpha 약0.522, roughness 약0.0196, metallic0이다. KP2의 기존 표현은 기준으로 보존한다.
- AirTaxi에는 별도 유리 재질, Joby 비행 모델에는 별도 창문 재질, X57에는 합성 창문 형상이 있다. EVTOL은 동체와 창문이 같은 텍스처/재질이므로 동체 전체에 투명도를 적용하지 않는다.
- 기존 카메라는 외부 orbit 및 spring arm 방식이다. 조종석 눈 위치는 이 외부 추적 오프셋으로 대신하지 않는다.

## 선택한 구현 방식

정적인 조종석 사진을 화면에 덮는 방식은 채택하지 않는다. 실제 기체 내부에 실내 구조를 배치하고, 기종별 눈 위치에서 외부 지도와 창틀이 함께 보이는 방식을 사용한다. 실시간 계기 화면은 실내의 화면 평면에 정합한다. 공통 계기 구성은 재사용하되 화면의 위치와 크기, 눈 위치는 기종별로 다르다.

실내 원형은 좌석, 바닥, 측면 내장, 전방 대시보드, 화면 및 베젤, 간단한 사이드스틱으로 구성한다. 장식용 조종간은 실제 조종 명령을 만들지 않는다. 좌석 원형은 반복 인스턴스로 재사용한다. 전 기체를 매 프레임 고해상도 실내로 그리지 않고 선택 기체만 상세 계기를 활성화한다.

## 기종별 크기와 창문 검증

1. 현재 비행 모델의 실제 변환, 단위, 축과 스케일을 읽는다. GLB 기본 자세뿐 아니라 실행 중 표시하는 모델 행렬과 표시 스케일을 동일하게 사용한다.
2. 창문 및 객실 형상의 경계로 실내 배치 가능 영역을 정한다. 로터, 날개, 꼬리까지 포함한 전체 bounding box 중심으로 조종사 위치를 추정하지 않는다.
3. 기종별로 조종사 좌석, 눈 위치, 전방 방향, 계기판 평면, 승객 좌석 배치를 작성한다. 내부 부품을 객실 폭·높이·길이에 맞추되, 기체 전체의 외형 크기와 지상 접촉 높이는 변경하지 않는다.
4. 정면 시야에서 전방 창문을 통과하는지, 계기판이 주 시야를 가리지 않는지, 좌우를 돌아볼 때 머리가 창틀/천장/벽을 통과하지 않는지 확인한다.
5. 일반/비행 모델에서 창문, 동체, 로고, 기존 로터·틸트·조종면이 보존되는지 확인한다. 새 좌석이 이미 존재하는 실내 부품과 겹치면 해당 기종의 중복 부품을 제거하거나 원래 좌석을 재사용한다.
6. 다섯 기종마다 외부, 조종석 정면, 좌우 시야의 실제 렌더 결과를 보존한다. 모든 기체에 같은 눈 좌표를 복사하는 것을 수용하지 않는다.

모든 조정은 시연용 시각 자산에 한정한다. 물리 질량, 관성, 실제 정원, FastPhysics/SimpleFlight 및 항로/게이트 치수는 변경하지 않는다.

## 카메라 동작

- 기체 정보창에 `외부 추적`과 `조종석` 시야 버튼을 둔다. 지원 자산이 준비되지 않았거나 대상이 사라지면 명시적인 대기/사용 불가와 외부 시야 복귀를 제공한다.
- 조종석의 위치는 기종별 눈 위치에 고정한다. 드래그는 상대 yaw/pitch만 바꾸며 벽을 관통하는 이동, orbit, WASD 지상 이동은 조종석에서 적용하지 않는다.
- 휠은 거리 이동이 아니라 perspective FOV만 변경한다. 기본60도, 범위35~90도로 제한한다. 원위치/정면 버튼으로 기준 시선을 복원한다.
- 실제 화면에 보이는 기체의 보간된 위치/자세와 동일 프레임에서 카메라를 갱신한다. 별도의 수신 최신 상태를 붙여 기체와 카메라 사이의 시간 차이를 만들지 않는다.
- 작은 각도 떨림만 완충한다. 카메라 위치가 기체 밖으로 늦게 따라오는 장거리 spring offset은 사용하지 않는다.
- 가까운 계기/창틀이 잘리지 않도록 조종석 모드의 near plane을 조정하고, 종료 시 기존 frustum/지도 입력 설정을 복원한다.
- ESC 또는 외부 추적으로 복귀할 수 있다. 기체 전환, 삭제, epoch 변경, 2D 전환 및 종료 시 조종석 자원과 입력 상태를 정리한다.

## 실시간 계기와 상호작용

전방 화면은 세 역할로 구성한다.

1. PFD: 인공수평선, pitch/roll, 방위, 속도, 고도 및 수직속도. 속도와 고도는 제공된 값의 종류/기준을 표시하고 지상속도를 IAS, 해발고도를 AGL로 바꾸어 부르지 않는다.
2. NAV: 선택 기체 중심 heading-up 경로/주변 교통, 다음 목적지/경유점 및 기존 PRISM 정보 진입. 전체 Cesium 지도를 두 번째로 생성하지 않고 가벼운 지도/레이더 표현을 재사용한다.
3. SYSTEM: 배터리, 로터 RPM, 틸트, 모드, 임무 단계와 데이터 수신 상태. 값이 없으면 미수신으로 표시하며 임의의 정상 수치를 채우지 않는다.

화면 버튼은 PFD/NAV/SYSTEM 페이지, 지도 범위, 방위 표시 방식과 밝기 등 표시 조작만 수행한다. PSU 허가, 조종사 목표, 스로틀, 틸트 및 비행계획 변경 API는 호출하지 않는다. 계기판 위 휠/클릭은 배경 지도와 조종석 카메라 입력으로 중복 전달하지 않는다.

계기는 장식 이미지가 아닌 실제 관측값을 사용한다. 숫자 자리는 고정 폭으로 유지하고 경고 영역을 예약해 미수신 문구로 화면이 들썩이지 않게 한다. 수치 갱신은 최대10Hz로 묶으며 자세 표시의 자연스러운 갱신은 기존 표시 시계를 따른다. 실시간 화면 텍스처/평면은 재사용하고 매 프레임 모델이나 WebGL context를 만들지 않는다.

## 사운드

기존 선택 기체 사운드와 동일한 대상/보간 상태를 유지한다. 조종석 진입이 선택을 해제하거나 자동으로 음소거하지 않는다. 사용자가 음소거해둔 경우 임의로 켜지 않는다. 실내에서의 음량은 제한하여 카메라 거리0 근처에서 갑자기 과도하게 커지지 않게 한다. 필요 시 완만한 실내 필터를 사용하지만 실제 소음/방음 측정값이라고 표시하지 않는다.

## 계층 및 변경 단위

- Model Library: 파생 실내/창문 자산과 기종별 cabin eye/screen/seat 정적 배치 메타데이터.
- Project Support: 재현 가능한 GLB/실내 생성·검사 도구, 원본 백업 및 렌더 증거.
- Visualization: 실내 표시, 기종별 모델 좌표 변환, 조종석 카메라 및 화면 평면 렌더링.
- User Application Web: 시야 버튼, 읽기 전용 계기 상호작용, 사운드 조립 및 표시 생명주기.
- Runtime/Data/AI: 기존 불변 공개 상태와 예측을 읽을 뿐 새 현재 상태 소유자를 만들지 않는다.

작업은 (1) 자산/창문/배치 계약, (2) 카메라, (3) 계기판, (4) 통합/사운드/실제 렌더 검증으로 나눈다. 각 단위는 인접 회귀를 먼저 추가한다. 자산 metadata 확장은 ADR에 기록한다.

## 수용 검사

- 다섯 기종의 승객 좌석 수와 별도 조종사 좌석, 창문만 투명한 상태, 눈 위치의 객실 내부 배치.
- 정면/좌우/휠 최소·최대 화각에서 창밖과 대시보드가 함께 보이며 눈 위치가 이동하지 않음.
- 기체 이동·회전 중 카메라/모델/계기가 같은 표시 시간을 사용함. 정지, stale, epoch 변경에서 이전 비행의 값이 남지 않음.
- 계기 화면 클릭과 휠 조작이 지도/운항 명령으로 전파되지 않음. 없는 입력을 표시값으로 꾸미지 않음.
- 외부/조종석 반복 전환 및 다른 기체 선택 후 frustum/입력/사운드 상태 복구. 상세 자산과 계기 갱신 루프 누적 없음.
- 실제 Cesium 렌더를 기종별로 확인하고 Console 오류, 로터/틸트, 표면 clipping과 투명도 정렬을 확인. 자동 회귀 통과만으로 시각 검증을 대체하지 않음.
- 운영 서버/비행 재시작은 구현 과정에서 임의로 수행하지 않음. 원격 반영과 실행 중 탭 재로딩 여부는 별도로 명시.

## 제한

실내 치수는 창문과 객실 외형에 맞춘 시연용 재구성이며 제조사 조종석/좌석 규격을 재현한 것이 아니다. 바깥 기체의 물리적 치수를 변경하지 않으므로 정원에 맞춰 실내 원형을 축소할 수 있다. 사용자 스피커 청취와 실제 Unreal 임무 검증 없이 전체 시뮬레이터 검증 완료라고 주장하지 않는다.
