# 0055: 지도 정보 조회와 카메라 추적 분리

날짜: 2026-09-11

## 결정

우클릭은 카메라 선택을 변경하지 않고 정보창만 연다. 추적 중 빈 지도를 우클릭하면 추적 대상을 다시 읽는다. 배치 도구와 버티포트 편집 메뉴는 기존 우선순위를 유지한다. Cesium RIGHT_CLICK에만 연결하며 RIGHT_DOWN이나 드래그 동작은 재정의하지 않는다.

LiveGlobe의 `selected`는 기존 카메라 및 경로 선택을 유지한다. 선택적 `detailId`는 정보 조회 대상 ID만 보관하고 현재 상태를 복제하지 않는다. `onSelect`의 선택적 두 번째 인수 `{reopen:true}`로 명시적 재열기와 일반 snapshot 갱신을 구분한다. 일반 갱신으로는 사용자가 닫은 창을 열지 않는다.

`detailsTracked()`는 정보 대상의 추적 여부를, `focusDetail()`은 사용자가 정보창에서 명시적으로 대상 보기/추적을 누른 경우의 전환을 맡는다. `select`의 `preserveDetails`는 추적 대상 소멸 시 여전히 유효한 별도 조회 대상을 유지하는 데만 사용한다. 서버 계약, 비행 상태, 물리 실행은 변경하지 않는다.

## 검증

우클릭 복원, 다른 대상 조회 중 추적 유지, snapshot 갱신, 정보 대상 및 추적 대상 소멸, 기존 배치 도구 우선순위를 회귀시험으로 검증했다. 별도 Chrome/Cesium 화면에서 정보창 닫기 후 우클릭 복원과 동일한 카메라 offset을 확인했다. 실제 우클릭 드래그 수동 검증과 전체 Unreal 임무 검증은 수행하지 않았다.
