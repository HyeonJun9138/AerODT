# ADR 0098: 조건부 주기장 후진 선회 경로

## 범위

시나리오 지상 gate_out 시작 시 기수가 출발 접선과 반대(8도 이내)이고 직선 구간이10m 이상인 경우, 저속 후진 직선과1/4원 선회 뒤 속도0에서 전진1/4원으로 전환하는 경로를 시도한다. 실제 조향/견인차 동역학이 아닌 지상 운동학 표현이다. 초기 진행 방향이 이미 전진인 경우 기존 경로를 유지한다.

후진 속도는 최대1.5m/s, 기존 가감속과 yaw 제한을 이용한다. 후진에서는 경로 접선과 기수 방향이 반대이고, 기어 전환점의 기수 방향은 연속이다. 바뀐 Phase 경로를 지상 이동권에 동일하게 전달하며 화면만 따로 움직이지 않는다.

## 제약 및 미완료

데크 경계에서 기체 반경7m 여유와 탑승시설/충전기의 보수적 외접원 여유를 검사한다. 좌우 후보 모두 통과하지 못하면 기존 동작을 유지한다. 기본 시험 데크는 B1/B2/C2와 이 검사에서 겹쳐 실제 후진 활성화되지 않았다. 이 사례의 주기장 출발 개선은 미완료이다. 부지별 실제 여유에 맞춘 동선 설계/정밀 시설 외곽 검증이 남아 있으며, 충돌을 무시하지 않는다.

독립 경로 시험에서 좌우 선회 모두 정지점 통과와 완료를 확인했다. native1/4FATO 기존 임무 회귀는 통과했지만 기본 데크 후진이 적용됐다는 증거가 아니다. 운영 화면/실제 재출발/Unreal은 미검증. 서버 재시작 없음.
