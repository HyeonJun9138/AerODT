# ADR 0097: 서로 다른 FATO 경로 선점 완화와 체공점 획득

사용자 요청에 따라 같은 버티포트의 서로 다른 FATO는 공통 WP가 있더라도 정적 터미널 경로 전체를 예약하여 서로 막지 않는 연구 가정을 추가한다. assume_distinct_fatos_separated 기본 true, 다음 계획 로드부터 적용한다. 다른 버티포트 및 같은 FATO의 동방향 차단은 기존대로 유지한다. 실제 관측 교통 대응과 패드/인접 패드/지상 점유 검사는 바꾸지 않는다. 실제 분리 항로나 우측 오프셋을 생성하는 변경이 아니다.

체공점은 이동 중에도 수평15m, 수직5m, 속도2m/s 미만 및 수직속도0.5m/s 미만이면 획득으로 판정한다. 최초 획득 당시 관측 위치를 settled_target에 고정하고 정확한 중심점을 다시 쫓지 않는다. 예약 target은 보존하고 매 틱 목표를 현재 위치로 덮어쓰지 않는다. 접근 복귀 시 settled_target을 제거하며 복귀 WP 획득 및 native 내부 경유점 진행은 변경하지 않는다.

사진의 왕복 현상에 대한 실시간 원인 확정은 아니다. 허가 취소/재허가 반복, native 조종 및 복귀 WP 진행은 추가 관측이 필요하다. 수정 전 실패 시험과 수정 후 체공 고정점, 서로 다른 패드, 같은 패드/다른 버티포트 회귀 및 native 1/4FATO 시험으로 확인한다.
