# 0113 새 계획의 수동 첫 편 우선 배치와 입력 설정 보존

2026-09-21

## 결정

계획 생성 요청 version 1에 선택적 `manual: {want, seats, vertiport}`를 추가한다.
생략하거나 want가 false이면 종전 순서를 유지한다. 서버는 인승 4/6/8 및
선택 범위 내 출발지를 검증하고 순수 스케줄러에 필터를 전달한다.

시간순 처리를 유지하면서 같은 준비 시각의 최초 후보 중 조건에 맞는 기체를
먼저 검토한다. 첫 편이 생성되면 보통 순서로 복귀한다. 수요, 연결 항로,
FATO 자원 간격과 반복운항 정비시간은 우회하지 않는다. 운항 중 인계나 이미
생성된 CSV의 시각은 변경하지 않는다. 조건을 만족하지 못하면 결과 notes에 알린다.

## GUI 설정

폼 입력만 브라우저 localStorage의 `aerodt.uam.demand_preferences.v1`에 저장한다.
새 창과 새로고침에서 복원한다. 생성 결과, runtime 상태, 서버 기준 수요는 저장하지
않는다. 사용자의 명시적 초기화는 저장값도 갱신한다. 다른 브라우저 및 다른
서버 주소로 동기화하지 않는다. 저장 차단/잘못된 JSON 때문에 폼이 중단되지 않는다.

## 검증

선택 인승 첫 슬롯, 1회 우선권 후 순서 복귀, 출발지 필터, 자원 간격,
반복 생성 결정성, 요청 전달, 입력 복원 및 명시적 초기화를 회귀시험한다.
