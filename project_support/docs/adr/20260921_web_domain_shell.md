# ADR: 명시적 웹 도메인 선택과 UAM 화면 소유권

상태: 프런트엔드 1단계 적용

## 배경

기존 웹 셸은 준비 직후 서울로 진입하며 Live Twinning, 운항 분석, 예측, 설정과 사운드가 UAM에 직접 결합되어 있었다. 위성 도메인을 추가할 때 메뉴만 숨기면 UAM 조회와 음향이 계속 활성화될 수 있다.

## 결정

- 시작 시 Satellite/UAM을 명시적으로 선택한다. 이전 선택을 자동 적용하지 않는다.
- 기존 UAM 구현은 기능별 도메인 폴더로 이동하고 구 경로는 re-export로 호환한다.
- 기존 공용 Cesium 뷰어와 WebSocket을 유지하되 표시 스냅샷, 자료 설정과 GUI는 선택된 도메인으로 제한한다.
- UAM 폴링, 재생 예측, 초기 운항 조회와 음향은 UAM 선택 뒤 활성화한다.
- Satellite에는 기존 위성 표시만 연결한다. 미구현 계획/분석 기능은 명시하며 UAM 화면을 재사용해 구현된 것처럼 보이지 않는다.
- 도메인 변경은 사용자 확인 후 페이지 재진입으로 처리한다. 서버 공유 상태는 reset하지 않는다.

## 영향과 비범위

공개 wire schema, 모델 패키지, 물리 실행 순서와 서버 상태 소유권은 변경하지 않는다. 공유 서버의 UAM 처리까지 정지시키는 실행 격리는 아니다. 완전한 lazy import, 서버 혼합 코드 분리, 우주 동역학과 위성 임무계획은 후속 범위다. 기존 UAM 빌드 기준선은 유지한다.
