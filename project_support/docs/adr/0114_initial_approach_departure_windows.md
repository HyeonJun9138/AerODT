# 0114 초기 접근 예약 중 자동 출발 시간창

2026-09-21

## 문제와 결정

지상 이동 권한은 관측된 지상 기체와 이미 부여한 이동 범위를 사용한다.
접근 기체가 아직 착륙하지 않았다는 이유로 실제 지상 점유를 해제하지 않는다.
별도의 터미널 예약은 초기 접근 시 전체 강하/착륙 경로를 예약했으며,
출발편이 먼저 존재할 때만 앞부분으로 축소했다. 이 순서 의존을 제거한다.

예측 접근이 활성화되고 최종 진입 전이라면 기존 제동거리 검사를 통과한
초기 접근 경로만 예약한다. 출발 검토에서는 현재 위치로 계산한 도착 잔여
시간에서 최종 진입/혼합 운항 간격과 ETA 여유를 뺀 시각을 사용한다.
출발의 지상이동, 이륙, 상승 전체 예상시간이 그 시각보다 짧아야 허용한다.
실제 패드 점유와 초기 접근 경로 자체의 교차는 계속 출발을 막는다.

관측이 없거나 정지, 고장, 수동 기체처럼 이 예측으로 완료를 보장할 수
없는 경우에는 시간창 이용을 허용하지 않는다. 허가 후 지상이동이 지연되면
출발의 실제 예약을 유지하고 도착은 최종 진입 재검사에서 기다린다. ETA를
이유로 실제 기체나 누락된 관측의 지상 권한을 제거하지 않는다.

PSU는 `arrival_window_too_short`와 `departure_window_unproven`을 구분해
대기 이유를 안내한다. 슬롯/운항 상태는 기존 소유자가 그대로 관리한다.

## 검증 범위

접근 먼저 예약, 출발 시간 여유/경계값/부족, 수동 예측 거부, 실제 패드와
터미널 점유 유지, 출발 중 최종 접근 확장 금지를 시험한다.
실제 native runner 및 실행 중 시뮬레이션 성능 검증은 별도 필요하다.
