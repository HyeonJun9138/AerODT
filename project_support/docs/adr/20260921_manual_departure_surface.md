# 수동 세션의 출발 데크와 초기 고도 일치

## 배경
수동 초기화는 시나리오의 기체 고도를 원점으로 삼지만, 접촉면은 브라우저가 보낸 렌더링 데크로 구성했다. 두 고도가 다르면 무입력으로도 공중에서 시작하거나 데크 아래에서 시작한다. 실제 실패 로그에서는 중립 입력으로 0.504초 동안 약 1.19 m 하강했다. 당시 데크 높이는 기록되지 않아 실제 차이의 크기는 확정하지 못했다.

## 결정
기존 handshake 형식은 유지한다. 계획의 deck datum 또는 출발 버티포트 ID를 가진 세션은 해당 ID의 유일한 검증된 contact_decks 항목을 요구한다. 계획의 출발 GATE 좌표가 그 다각형 안에 있을 때에만, 런타임 생성 전에 해당 데크 높이로 초기 원점을 정한다. 수평 좌표는 변경하지 않는다. 데크가 없거나 중복되거나 GATE가 밖에 있으면 명시적인 오류로 거부한다. 데크 기준이 없는 기존 로컬 평면 시험 경로는 유지한다.

이는 세션 접촉면을 사용하던 기존 계약을 일관되게 적용하는 초기 구성 수정이다. 실행 중 위치 변경, 접촉 flag 위조, 무제한 초기화 대기는 추가하지 않는다. 데크 데이터의 신뢰 범위를 새로 확장하지 않는다.

## 입력
조종석 준비가 끝날 때까지 resume 및 조작 전송을 잠근다. 로딩 중 누른 키의 자동 반복은 준비 후 새 입력으로 인정하지 않으며, 놓았다가 다시 눌러야 한다.

## 검증과 한계
위/아래 고도 불일치를 native runtime으로 재현하고, 일치시킨 구성에서 실제 접촉과 정지 상태를 검증한다. 누락/중복/영역 밖 데크 거부, 준비 중 전송 차단, 키 반복 차단을 회귀시험한다. 실제 VP012 실패 당시 데크 높이와 서버 적용 후 실기동은 별도 검증이 필요하다.
