# ADR 0027: 웹 계획 비행의 완만한 유도와 실제 접지 확인

- 상태: 채택
- 날짜: 2026-09-10

## 문제

저장된 VP001 → VP005 실행에서 착륙 종료 시 아직 2.52 m 높이에 있고
FATO 중심에서 7.59 m 벗어나 있었으나, 포획 반경 안에 들었다는 이유로
지상이동으로 넘어갔다. 접근 끝의 60 m 포획 반경, 수직 구간에서 속도 제한을
우회하는 위치 목표, 계획 고도로의 표시 대체가 겹쳤다. 강하에서 착륙으로
넘어가는 표시 고도 차이는 24.22 m였다. 위치 제어와 속도 제어의 교체도
틸트 출력을 불연속으로 만들었다.

## 결정

`uam_flight_runner` 입력에 선택적 `smooth_flight 0|1`을 추가한다. 생략하면
기존 유도 방식이다. 웹 native adapter는 1을 명시한다. 기존 6개 필드의
waypoint와 출력 state 숫자 형식은 유지한다.

완만한 모드는 패드에서 6초 동안 실제 로터 actuator를 가동하고, 시작 위치를
기체 지상 여유 높이에 맞춘다. 다음 4초의 선택적 throttle 시작 곡선과
가속도 제한 속도 목표로 수직 이륙한다. 상승 중 출발 방향으로 yaw 목표를
초당 10도 이내에서 바꾸고, 실제 방향 정렬 후 수평 가속한다. 수직 구간도
동일한 속도 제어 경로를 사용하여 제어기 교체에 따른 틸트 초기화를 피한다.

접근 마지막 hover는 0.6 m 이내에서 속도 0.4 m/s 미만으로 1초 안정해야
통과한다. 수직 하강은 중심 0.3 m 이내, 수평 속도 0.2 m/s 미만, 역틸트
완료 조건을 확인한 뒤 시작한다. 1 m 이상 벗어나면 hover 높이를 다시
목표로 삼는다. 하강 목표는 최대 1.2 m/s이고 접지 부근에서는 0.18 m/s까지
낮춘다. 마지막 지점은 거리만으로 완료하지 않으며 실제 grounded와 중심
0.3 m 이내 조건이 2초 유지되어야 완료한다. 접지 후 지상 idle 명령을 유지한다.

SimpleFlightParameters에는 선택적 `startup_initial_throttle`, `startup_ramp`,
`transition_duration`을 추가한다. 기본은 시작 곡선 없음과 기존 5초 전환이다.
이 웹 실행 호스트만 4초 시작 곡선 및 12초 전환을 선택한다. 이는 운용
명령의 변화율이며 질량, 공력, mixer, rotor 물성의 별도 복제본이 아니다.
FastPhysics 이산 실행 순서와 상태 소유권은 바꾸지 않는다.

## 기록 및 표시 호환성

native 상태의 `altitude_m`는 실제 물리 상대 고도다. 선택 필드
`planned_altitude_m`, `height_error_m`에 계획 고도와 물리 고도의 차이를
기록한다. 브라우저는 기존 지형/데크 기준으로 해석한 계획 고도에 이 차이를
더한다. 필드가 없는 과거 기록은 이전처럼 재생하며 저장된 실행은 수정하지 않는다.
단계 경계에 작은 위치 표류가 있어도 완료된 단계로 되돌아가는 메타데이터
진동은 허용하지 않는다. 실제 위치나 속도를 스냅하지는 않는다.

접지와 지상이동의 중복 timestamp를 제거한다. 지상 rotor는 실제 물리
telemetry인 `rotor_radps`를 조작하지 않고 선택 필드 `rotor_visual_radps`,
`motor_state`, `rotor_source: ground-visual-indication`으로 구분한다.
지상이동 중 idle을 유지하고, 게이트 정지 후 마지막 6초 동안 shutdown한다.
필요하면 ground_motion 끝에 정지 시간을 추가하고 에너지/시간을 재계산한다.
충전 단계는 rotor off다. 별도 사용자 시동 버튼을 추가하는 변경은 아니다.

## 검증 및 한계

동일 저장 경로 재실행, 독립 6-waypoint 회귀, 제어기 시작 곡선 회귀,
브라우저 실제 AirTaxi 모델 재생으로 확인한다. 근거는
`data/development_log/evidence/2026_09_10_smooth_native_flight.json`에 기록한다.

현재 물리 접촉은 평면 기준이다. 지형/옥상 높이는 브라우저 기준값으로
해석하므로 서로 다른 실제 표고에서의 착륙 역학 검증이나 장애물 회피를
대신하지 않는다. 지상이동과 지상 rotor 표시는 여전히 운동학/시각 표현이다.
운용 envelope의 실항공기 인증, 전체 임무/Unreal 실실행 검증은 별도다.

## 후속 수정: 역전환 시작 시점 앞당김 (2026-09-10)

완만함은 시작 지연이 아니다. 기존 native adapter는 강하 각 선분의 60%까지
fixed_wing을 요청해 짧은 접근에서 역전환이 늦었고, 여러 선분에서는 다시
fixed_wing을 요청할 수 있었다. 이제 강하 전체 수평 길이의 15% 이내에서
한 번만 역전환을 시작한다. 접근 종료까지 속도 기준 18초(기존 전환 12초와
여유 6초)의 거리를 확보하도록 더 앞당기며, 그보다 짧으면 시작부터 전환한다.
고정된 시간 보장은 아니며 실제 제어 반응은 실행 기록으로 검증한다.
전환 소요 시간/변화율과 FastPhysics 실행 순서는 바꾸지 않는다.
저장 경로 재실행에서 강하 heading 누적 변화 403.69→34.56도,
멀티로터 복귀 진행률 0.747153→0.135832, 최대 틸트 변화율 7.5도/초 유지,
실제 grounded와 종료 속도 0을 확인했다. 강하 시간은 160.2→167.6초다.
이전 저장 실행은 재작성하지 않으며 새 실행 생성부터 적용된다.
