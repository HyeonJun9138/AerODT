# ADR 0029: 계획 기반 승객 탑승 표시

날짜: 2026-09-10
상태: 적용

## 결정

웹 비행계획에 선택적인 `boarding`, `alighting` v1 필드를 추가한다. 기존 계획 형식과 단계 ID는 유지한다. 필드가 없는 과거 실행은 이전처럼 재생하며 기록을 소급 변경하지 않는다.

- 계획의 passengers 수와 출발 gate에 연결된 boarding_points 시설을 사용한다. 승객 0명 또는 시설 없는 구형 배치는 필드를 생성하지 않는다.
- `path`, `distances_m`, `release_s`, `walk_s`, `enter_s`, `duration_s`가 결정적인 시간표를 구성한다. 좌표는 경위도이며 `datum`은 출발 데크다. `gate`, `facility`, `count`, `asset_id`, `height_m`, `source`를 함께 기록한다.
- 시설과 충전함의 확장 사각형을 피해 데크 내부 동선을 계산한다. 불가능한 동선을 건물을 관통하는 직선으로 대체하지 않는다.
- 기존 gate_out ground_motion의 최초 대기 시간을 전원 탑승 완료 후 최소 약 2초까지 연장한다. 이후 계획 시간과 에너지 계산에 반영한다. 별도 군중 상태나 runtime 소유권을 추가하지 않는다.
- 도착 게이트의 시설로 돌아가는 별도 `alighting` 동선을 만든다. `start_stage: charge`이며 실제 재시간화된 충전 단계 시작을 기준으로 1초 후부터 같은 인원을 내린다. 절대 출발 시각을 저장하지 않아 native 비행 시간 변화에도 동기화된다. 마지막 구간만 시설 출입구 안쪽으로 들어가며 그 후 숨긴다.
- `charge.passenger_hold_s`는 하차 완료를 위한 최소 게이트 체류 시간이다. 충전 목표가 이미 충족돼도 이 시간을 남기며 native retime도 보존한다. 추가 충전 에너지를 만들어 내지 않는다. 하차 중 이미 충전 목표에 도달하는 경우 이 단계에는 체류 대기가 포함된다.
- 렌더러는 재생 시각으로 위치와 탑승/시설 도착 수를 계산한다. 실제 관측 승객이 아니라 `planned-passenger-visualization`이다. 시뮬레이션 물리 스텝 순서는 바꾸지 않는다.

## 렌더링 비용

현재 기체 정원 최대 4명만 표시한다. 650m 이내의 진행 중 탑승/하차에 한해서 모델을 지연 로딩한다. 동일 Kenney CC0 소형 GLB URI와 동일 모델 풀을 출발/도착 양쪽에서 재사용하며 별도 타이머, API polling 또는 승객별 지형 질의를 만들지 않는다. 멀리 있거나 이동이 완료된 사람은 숨기고, 계획 해제 시 primitive와 늦게 완료되는 로드를 정리한다. 되감기용 풀은 계획 정원으로 제한한다.

걷기는 모델의 기존 walk clip과 재생 시각을 연결한다. Cesium의 ready 이후 animation 추가 및 사용자 정의 animationTime 규칙을 따른다: https://cesium.com/learn/cesiumjs/ref-doc/ModelAnimationCollection.html , https://cesium.com/learn/cesiumjs/ref-doc/ModelAnimation.html

## 한계

객실 진입점은 대표 위치이며 실제 출입문 메타데이터가 아니다. 문 열림, 좌석 착석과 군중 충돌 물리는 미구현이다. 다른 기체/로터의 안전 영역을 검증한 공항 운영 동선으로 사용하지 않는다. 사람 키 1.75m는 표시용 스케일이다. 실측 승객 정보로 해석하지 않는다.

## 검증

최종 Python 관련 73개와 Node 관련 29개 통과. 전 배치 패턴/회전/게이트의 출발 및 도착 경로, 정원별 탑승 후 이동, 짧은 충전 하차 대기와 native retime, 되감기, 거리 제한 및 늦은 로드 해제를 검증했다. 독립 Cesium 브라우저에서 실제 시설/기체/사람 모델 3명과 walk 노드 행렬 변화, 충전 중 하차와 건물 입장 후 숨김, 원거리 숨김 및 출발 복귀 시 동일 3개 풀 재사용을 확인했다. 실제 Unreal과 운영 중 사용자 서버의 새 실행 검증은 수행하지 않았다.
