# ADR 0096: 이착륙 우측 분리 연구 가정

사용자 요청에 따라 PSU의 `assume_mixed_separated` 정책을 기본 true로 추가한다. 다음 비행계획 로드부터 적용한다. 기존 저장 정책에서 생략된 값은 기본값을 사용한다.

TerminalReservations의 선택적 생성자 인자로 전달하며 arrival/departure 조합의 overlap만 생략한다. 이륙과 착륙 방향을 반대로 조회해도 동일하며, 대기 착륙편 우선권 검사에서 쓰는 overlap에도 적용된다. 직접 생성한 TerminalReservations는 기존 엄격 기본값을 유지한다. 같은 방향의 경로 중첩 및 예약 획득/해제는 유지한다.

이는 비행 측 우측 분리를 가정하는 연구 설정이지, 우측 항로 생성이나 실제 분리 보장이 아니다. 실제 관측 기반 근접 대응, 패드 점유, 인접 패드, 지상 출구 및 착륙 간격은 바꾸지 않는다. 특히 사용자가 제공한 화면의 착륙 출구 확보 대기는 별도 지상 판단이므로 이를 제거했다고 보고하지 않는다.

신규 회귀에서 혼합 방향만 해제되고 동방향과 실제 점유는 차단되는지 확인한다. 엄격 모드의 기존 초기 접근 시험은 명시적으로 가정을 끄고 유지한다. 운영 서버는 재시작하지 않는다. 전체 지상 출구 회귀 및 Unreal 검증은 별도 과제다.
