# ADR 0110: 접지 순서 GATE 배정과 FATO 중심 도착 대기층

## 상태

채택

## 배경

기존 도착 절차는 접근 허가 전에 GATE와 FATO에서 GATE까지의 지상경로를 함께
확보했다. 이 방식은 접지 뒤 빠져나갈 곳을 미리 보장하지만, FATO가 비어 있어도
GATE가 사용 중이면 긴 착륙 절차 전체가 공중에서 지연되는 문제가 있었다. 또한
대기 위치가 접근 진입점의 측면에 고정되어 실제 착륙 순번과 고도가 직관적으로
대응하지 않았다.

## 결정

도착 허가는 GATE 예약과 분리한다. PSU는 접근 요청을 받은 시점에는 FATO의 사용
가능 여부, 실제 점유, 선행 운항 간격과 터미널 경로 충돌을 판단한다. GATE가 아직
없더라도 FATO가 사용할 수 있으면 접근과 착륙을 진행할 수 있다.

실제 접지가 관측되면 PSU는 같은 버티포트에 접지한 기체를 `used_s`, 착륙 순번,
비행 식별자 순으로 처리한다. 각 기체에 빈 GATE를 배정하며, 시설별
`VertiportGroundControl`이 FATO에서 GATE까지 최단 경로와 실제로 존재하는 차선
경로를 제안한다. PSU는 현재 점유를 반영하여 완전히 비어 있는 경로를 먼저 고르고,
그다음 진행 가능 거리와 전체 거리를 비교한다. 실제 이동 허가는 기존
`MovementAuthority`가 계속 담당한다. GATE가 없으면 기체는 FATO에 정지하고 FATO
점유를 유지한다.

착륙 대기 순번은 동일 목적지 FATO별 실제 남은 항로 ETA가 짧은 순으로 매 판단마다
다시 계산한다. 1순위는 작성된 착륙 시작점보다 10 m 높은 층, 2순위는 20 m 높은
층이며 이후 순번도 10 m씩 높인다. 각 층에는 FATO 주위의 수평 후보를 두고, 출발
가능 FATO에서 이어지는 이륙 경로, 지형, 관측 기체, 다른 대기점과 이동 경로를
침범하는 후보를 제외한다. 순번이 바뀌면 새 층으로 이동하되 이동 전 전체 구간의
교통 분리를 다시 확인한다.

대기 해제 시 목적지는 기존 접근 진입점이 아니라 착륙 시작점이다. 기체는 분리
검사를 통과한 직선 이동으로 착륙 시작 고도에 들어가며, 최종 FATO 점유와 운항
간격을 다시 확인한 뒤 착륙한다. 수동 조종은 같은 상태에서 최종 착륙 허가를
요청하고, 자동 조종은 같은 재확인을 자동으로 수행한다.

자동 출발편의 목적지 대기점은 출발 지상이동 허가를 확정하기 전에 예약한다.
후보가 없으면 기체는 출발 GATE에 남는다. 종전처럼 GATE에서 FATO까지 이동한 뒤
native Pilot 시작 직전에 예약을 시도하면, 예약 실패가 출발 FATO 점유 상태를
무기한 유지하여 인접 착륙 FATO까지 막을 수 있기 때문이다. 출발 슬롯이 부여되지
않으면 이 판단 중 생성한 대기점 예약은 반환하고, 허가된 경우에만 계획 경로에
대기점을 확정한다.

## 책임

- 버티포트 운영자는 GATE/FATO 점유 사실, 지상 그래프와 복수 경로 후보, 실제
  지상이동 권한을 소유한다.
- PSU는 실시간 ETA 순번, 대기층, FATO 허가, 접지 순서 GATE 및 지상경로 선택을
  소유한다.
- Pilot은 지정 대기점과 착륙 시작점으로 이동하고 수동 또는 자동 절차에 따라
  허가를 요청한다.
- Simulation은 현재 위치와 접지 관측을 전달하고 선택된 목표를 실행할 뿐 자원이나
  순번을 독자적으로 결정하지 않는다.

## 결과

비어 있는 FATO를 GATE 사전 확보 때문에 놀리지 않으므로 공중 대기시간은 줄어들 수
있다. 반면 접지 뒤 GATE가 장시간 확보되지 않으면 해당 기체가 FATO를 막는다. 이는
숨기지 않고 FATO 점유와 `접지 순서 GATE 대기`로 보고한다. 따라서 처리량 개선은
GATE 회전과 지상경로 처리량이 따라올 때에만 보장된다.

목적지 대기점 부족으로 출발편이 멈추는 경우에는 출발 GATE가 사용되지만 FATO는
사용되지 않는다. 서로 다른 FATO는 거리로 점유를 공유하지 않으며, 같은 FATO가
점유된 경우에만 해당 FATO와 비행체 식별자를 최종 착륙 보류 안내에 포함한다.
서로 다른 FATO의 경로가 실제로 교차하면 별도의 터미널·지상경로 검사에서 제한한다.

이착륙 겸용 FATO가 여러 개인 시설에서 접지 대기가 출발 용량을 모두 닫는 문제는
[ADR 0111](0111_mixed_fato_departure_capacity_reserve.md)의 출발 FATO 보호 규칙으로
제한한다.
