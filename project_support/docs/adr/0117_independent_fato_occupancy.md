# ADR 0117: FATO별 독립 점유와 거리 기반 인접 폐쇄 제거

## 상태

채택

## 배경

기존 PSU 정책은 같은 데크의 FATO 중심 거리가 `pad_adjacency_m`보다 가까우면 한
FATO의 실제 점유가 다른 FATO까지 닫는 것으로 해석했다. VP011의 F1과 F2는 약
48 m 떨어져 있고 기본값은 50 m였으므로, F1 출발편이 F2 수동 착륙을 막았다.
이 값은 인증된 다운워시 기준이 아니라 연구용 보수 설정이었으며, 독립 자원으로
만든 FATO를 거리 하나로 다시 합치는 결과를 냈다.

## 결정

물리 점유는 동일한 FATO 식별자에만 적용한다. F1 점유는 F1만 닫고 F2를 닫지
않는다. `pad_adjacency_m` 정책 항목과 운영 화면 설정도 제거한다.

서로 다른 FATO 사이의 안전 판단 자체를 없애는 것은 아니다. 접근·상승 경로 중첩은
`TerminalReservations`, 지상 이동 교차는 버티포트가 제안한 경로와
`MovementAuthority`, 실제 공중 근접은 조종사 교통 대응이 각각 계속 판단한다.
출발 FATO 보호 용량도 서로 다른 FATO를 독립 자원으로 계산한다.

## 결과

서로 가까이 배치된 FATO도 식별자가 다르면 동시에 운용 후보가 될 수 있다. 따라서
레이아웃 작성자는 독립 운용이 불가능한 시설을 서로 다른 FATO로 모델링해서는 안
된다. 공용 물리면을 표현해야 한다면 같은 FATO 식별자를 사용해야 한다. 이 결정은
거리만으로 다른 FATO를 폐쇄하지 않는다는 시뮬레이션 계약이며 실제 운항 안전성이나
인증을 보장하지 않는다.

ADR 0095, 0096, 0097, 0099와 0110에서 인접 패드 점유를 유지한다고 적은 부분은
이 결정으로 대체한다.
