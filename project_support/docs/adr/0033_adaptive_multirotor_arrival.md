# 0033: 하강 전 역천이와 안정 확인

날짜: 2026-09-10

## 결정

RoutePilot의 smooth flight는 기존 항로를 따라 하강 시작점까지의 거리를
확인하고, 관측/명령 수평속도에 따른 감속 거리와 역천이 여유로 미리
멀티로터 복귀를 요청한다. 하강 목표점은 고정익으로 비행하지 않는다.
진입점에서 blend, 실제 틸트, 위치, 수평/수직속도가 안정된 상태를
1초 확인한 뒤 하강한다. 비수직 하강 명령은 2m/s 이하이며 짧고 급한
경로에서는 수평속도도 함께 줄인다. 물리 상태를 직접 보정하지 않는다.

RoutePilot::Update에 observed_tilt_deg 인수를 추가한다. 기존 호출의
소스 호환을 위해 기본값 0을 유지하지만, actuator를 가진 실제 실행자는
반드시 관측 틸트를 전달해야 한다. native runner는 매 tick의 틸트를
전달한다. wire schema와 저장 형식은 변경하지 않는다.

## 영향과 한계

기존의 하강 중 고정익 목표점 삽입을 없앤다. 실행 시간 제한은 낮아진
접근 속도와 고도차도 반영하여 계산하며 유한한 timeout은 유지한다.
기존 저장 실행은 변경하지 않고 새 계산부터 적용한다. FastPhysics 적분,
SimpleFlight 내부 및 actuator 파라미터는 바꾸지 않는다.

현재 수치(2m/s 하강, 접근 8m/s, 0.7m/s² 감속, 18초 천이 여유)는
현 native 기준선의 보수적 guidance 값이며 기종별 인증 성능이 아니다.
지형 회피, 실제 항공 안전성 및 다른 UAM 동역학의 검증을 대신하지 않는다.
분할된 하강 목표점에서는 기존 hover capture 규칙에 따라 정지할 수 있다.
