# 0092: 주변 교통 주입 시험 입력

브라우저의 단기 시험 객체는 World의 실제 관측이 아니므로 기존 GET 예측에 포함되지 않았다. 동일 출처 POST `/api/prediction/risk`에 `{epoch, tracks:[{entity_id, kind, samples:[[time,x,y,z], ...]}]}`를 선택적으로 전달한다. 좌표는 ECEF m, 시간은 현재 snapshot의 시간 기준이다.

요청은 64 KiB, 객체 8개, 객체별 20개 표본으로 제한한다. 실행 epoch, intruder 식별자, 종류, 유한 좌표, 시간 순서와 최근 10초 범위를 검사한다. 브라우저 세션별 식별자로 충돌을 방지한다. 입력은 요청용 snapshot에만 합쳐지며 World에 등록하거나 일반 GET에 공개하지 않는다. 이력은 기존 data의 제한된 RiskHistory에서 관리한다.

주입 표적은 0.5초 슬롯 3개 및 1초 이내 최신 관측으로 시험 추론을 허용한다. 빈 슬롯은 마스크로 남긴다. 기준 기체의 20개 슬롯 조건은 유지한다. 실제 PRISM 가중치를 사용하며 임의 예측선을 만들지 않는다. 결과에는 injected_test_state 및 가정한 관측 오차를 명시한다. 카메라 탐지와 구분하고 단기 입력의 정확도는 검증되지 않았음을 표시한다.

이는 연구용 2D 시험 연결이며 충돌 확률이나 자동 회피를 보장하지 않는다.
