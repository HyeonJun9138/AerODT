# Project Support

이 폴더는 AeroDT 실행 계층이 아니라 저장소 유지와 검증을 위한 지원 영역이다.

- `docs`: 아키텍처, ADR, 이식 및 로드맵 문서
- `tests`: 여러 계층을 함께 확인하는 통합, 회귀 및 실제 실행 검증
- `tools`: 빌드, 시험 및 개발 기록 도구
- `build`: CMake 생성물이며 Git에서 제외
- `environment`: 로컬 실행 환경이며 Git에서 제외

대용량 외부 원본과 연구 자료는 이 저장소에 복제하지 않는다. 필요한 기준 버전과
출처는 ADR과 manifest에 기록하고 별도 checkout 또는 공급자 저장소에서 받는다.

제품 코드, 모델 파라미터 또는 현재 시뮬레이션 상태를 이 폴더에 추가하지 않는다.
